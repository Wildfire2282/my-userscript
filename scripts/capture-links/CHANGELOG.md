# 变更记录

## 1.3.4 — 2026-10-26

- 内部整理：设置读取与保存跟其它脚本用同一套实现；悬浮按钮、复制格式与已有设置都不变。

## 1.3.3 — 2026-10-25

- 页面关掉后不再留下用不上的监听，下次打开是干净的；抓取、筛选、复制与权限都不变。

## 1.3.2 — 2026-10-25

- 链接很多的页面打开面板更利落，关掉面板后不再占着内存；页面刚加载时也不再提前准备看不见的设置窗口。
- 抓取、筛选、勾选、复制与外观保持不变，所需权限不变。

## 1.3.1 — 2026-10-24

- 修复页面指定资源目录时相对链接复制到错误路径，以及地址中的特殊文字被重复转换的问题。
- 日常链接筛选、复制操作和已有设置保持不变，所需权限不变。
- 修复提示被新消息覆盖、关闭后仍响应，以及重复打开表单时提示关联异常的问题。

## 1.3.0 — 2026-10-23

- 在另一个标签页改了复制格式，这个标签页不用刷新也立刻按新格式复制。

## 1.2.1 — 2026-10-23

- 链接很多时反复筛选不会再让页面越用越卡：「显示更多」按钮不再每次都留下一个残留监听。

## 1.2.0 — 2026-10-23

- 菜单名与其它脚本统一：原来的「面板」改叫「操作面板」，「设置」改叫「功能设置」，面板标题同步。功能不变。

## 1.1.1 — 2026-10-23

- 修好右下角按钮：点开时会直接列出本页链接，之前是一片空白，只有从菜单打开才有内容。
- 链接超过 200 条时，「全选」会选中全部筛选结果，复制条数与顶部统计一致；之前只选前 200 条。

## 1.1.0 — 2026-10-23

- 链接面板和设置窗口换成与其它脚本一致的外观，居中显示，窄一些；点面板外面不再关闭，用 × 或 Esc 收起。
- 右下角按钮换成统一的链接图标；位置不变，仍是点一下打开链接面板。
- 复制结果改用统一提示条，条数照旧；剪贴板写不进去时会明确说没复制成功。
- 功能不变：抓取本页链接、关键词筛选、仅磁链、全选 / 全不选 / 反选、纯链接 / Markdown / HTML 三种复制格式。
- 老设置（悬浮按钮开关、复制格式）原样保留，升级后不需要重新设置。

## 1.0.1 — 2026-10-23

- 补充作者主页、问题反馈链接与英文名称、英文简介；功能不变。
