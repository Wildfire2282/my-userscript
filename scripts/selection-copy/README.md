# 选中复制

选中文本后自动纯文本复制到剪贴板，去除首尾空白；复制成功会在选区旁显示「已复制」。

| 项目 | 值 |
| --- | --- |
| Greasy Fork | [582576](https://greasyfork.org/zh-CN/scripts/582576) |
| 当前版本 | 1.4.9（2026-10-26） |
| 迁移状态 | 已迁移：`src/` 模块，界面使用 `@ui` |
| 匹配站点 | `*://*/*`（`document-end`，每个 frame 独立生效） |
| 授予权限 | `GM_setClipboard`、`GM_getValue`、`GM_setValue`、`GM_registerMenuCommand` |
| 设置键 | `selection-copy:config.settings` |
| 设置入口 | 脚本管理器菜单 →「功能设置」 |

## 行为

| 操作 | 结果 |
| --- | --- |
| 拖动选中文字后松开 | 自动复制选中的文字，去掉首尾空白，并在选区旁显示「已复制」 |
| 双击 / 三击选中文字 | 自动复制 |
| Shift + 方向键 / Home / End / PageUp / PageDown 扩选 | 自动复制 |
| Ctrl+A（Windows） | 自动复制 |
| 普通单击（只移动光标） | 不复制 |
| 在输入框、富文本编辑器里选中 | 默认不复制；可在设置面板里打开 |
| 程序化选区（页面脚本改的） | 不复制，只认用户手势 |
| 剪贴板写入失败 | 显示「复制失败」约 1.8 秒，不再无声失败 |
| 提示标签 | 成功显示约 1.2 秒后淡出；贴在鼠标松开点正上方，上方放不下时翻到下方；键盘选区（Shift 扩选、Ctrl+A）贴在选区焦点处；不遮挡点击 |
| 在设置面板里选中文字 | 不复制，避免覆盖剪贴板 |

与旧版一致：只接受 `isTrusted` 的鼠标与键盘事件；页面合成的 `mousedown` / `mouseup` / `keyup` 不算数。

手机长按选中暂不支持：本次只保证电脑端，触摸选区交给系统菜单的原生复制。

## 设置

从脚本管理器菜单打开「功能设置」，改动立即生效，没有保存按钮：

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| 启用选中复制 | 开 | 总开关；关闭后所有网站都不复制，菜单入口保留 |
| 当前网站 | 开 | 只关掉当前站点；按顶层页面主机名识别，同页 iframe 一起暂停，http / https 共用，本机文件记为 `file` |
| 输入框里也复制 | 关 | 打开后 `input` / `textarea` 里选中也会复制 |
| 富文本编辑器里也复制 | 关 | 打开后 `contenteditable` 区域里选中也会复制 |
| 去掉首尾空白 | 开 | 关闭后按选中的原样复制，保留两端的空格与换行 |

设置只存本地，不采集、不上报任何内容。关闭总开关或本站后只是不再复制，页面上的监听与已打开的面板都保留，重新打开立即恢复。

## 结构

```text
src/
├─ main.ts                    # 入口：安装传感器、注册菜单
├─ config.ts                  # 手势阈值、提示标签尺寸与停留时长
├─ settings.ts                # 设置 schema、归一化与存储
├─ feedback.ts                # 一次复制的结果（成功 / 失败 + 锚点）
├─ gesture.ts                 # 纯判断：拖动 / 双击 / Shift 扩选 / Ctrl+A
├─ selection.ts               # 选区、焦点、可编辑区域、输入框与自身界面门控
├─ features/
│  ├─ sensor.ts               # 鼠标 / 键盘监听，只收集快照
│  ├─ copy-action.ts          # 选来源 → 过门控 → 写剪贴板 → 产出反馈
│  └─ geometry.ts             # 焦点插入点、控件锚点与兜底矩形
└─ ui/
   ├─ app.ts                  # 共享 UI 宿主：第一次需要时才挂载
   ├─ indicator.ts            # 「已复制 / 复制失败」标签与淡出
   ├─ indicator-position.ts   # 位置计算（纯函数，含贴顶翻转）
   ├─ indicator.css           # 标签样式（只用 --ds-* Token）
   └─ settings-panel.ts       # 设置面板（@ui 组件组合）
```

命令见[docs/architecture.md](../../docs/architecture.md)第 5-6 节。

## 已知取舍

- 提示标签用中性卡片底 + 彩色图标，而不是整块填色：12px 文字在浅色主题的绿色 / 红色底上对比度不够；卡片底在浅色与深色主题下都能读清。
- 设置面板会多引入 `@ui` 的 Panel / Field / Switch 组件，产物体积约为 1.2.0 的 2.8 倍；面板只在第一次打开或第一次复制提示时挂载，页面空闲时仍只有事件监听。体积预算仍是 raw ≤ 200 KB / gzip ≤ 60 KB。
- 站点标识取顶层页面主机名：同源 iframe 直接读 `top.location`，跨域 iframe 用 Chromium / WebKit 的 `ancestorOrigins`，取不到时退回本帧。Chromium 下暂停顶层站点后，同页 iframe 的下一次复制也会停下。
- 设置菜单只在顶层页面注册，避免每个 iframe 各加一项、把面板塞进看不见的小 iframe。
- 每次复制前读取一次共享设置（复制是低频手势）；设置面板的开关、面板与提示共用同一个 `@ui` 宿主，关闭总开关不销毁 UI，重新打开时无需重建。
- 每个 frame 仍独立注入，没有加 `@noframes`：父文档收不到 iframe 内的鼠标事件，加了会丢掉 iframe 内的复制能力。
- 同一文档用 `data-selection-auto-copy-installed` 属性防重复注入；不再用 `window` 标记判断，避免不同管理器的沙箱之间判断不一致。
- 剪贴板优先用 `GM_setClipboard`，没有时依次退回浏览器剪贴板与隐藏 textarea；三条通道都失败才显示「复制失败」。
- 提示标签是 `@ui` Shadow Root 里的 `position: fixed` 标记：普通页面完全等价，宿主进入浏览器全屏时标记不会显示（旧版靠 popover 顶层也能显示）。
