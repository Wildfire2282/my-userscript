# 变更记录

## 1.4.11 — 2026-10-26

- 脚本关闭时收尾更干净：提示条与界面宿主一起释放；复制与提示效果不变。

## 1.4.10 — 2026-10-26

- 网页组件（Shadow DOM）里的正文选中现在也会自动复制。
- 在自己脚本的设置面板里选中输入框文字时，即使打开「输入框里也复制」也不会覆盖剪贴板。
- 设置字段重新出现时不再留下没有说明的红框。

## 1.4.9 — 2026-10-26

- 拖滑块、拖卡片等没有产生新文字选区的操作，不再把上一次的选区重复写进剪贴板；输入框里拖动选中仍照常复制。

## 1.4.8 — 2026-10-26

- 网页组件内部的输入框里选中文字时，也遵守「输入框里也复制」开关。
- 复制提示在部分页面（没有标准文档类型的旧页面）上不再跑到屏幕外。
- 焦点停在数字、日期等输入框时，备用复制通道失败也不会把错误抛给页面。

## 1.4.7 — 2026-10-26

- Shadow DOM 里的编辑器选中文字时，默认仍按「富文本编辑器」处理，不会自动覆盖剪贴板。
- 数字、邮箱等输入框里按 Ctrl+A 不会再绕过「输入框里也复制」开关。
- 复制提示贴边时不再压住页面滚动条。

## 1.4.6 — 2026-10-26

- 内部整理：设置读取与保存跟其它脚本用同一套实现；选中复制、本站开关与已有设置都不变。

## 1.4.5 — 2026-10-25

- 页面关掉后不再留下用不上的监听，下次打开是干净的；复制、设置、权限都不变。

## 1.4.4 — 2026-10-25

- 内部优化，没有可见变化：设置窗口里的「滚动查看更多」提示不再每次滚动都重新测量。
- 选中复制的行为与设置保持不变，所需权限不变。

## 1.4.3 — 2026-10-25

- 复制成功的提示改到鼠标松开的位置显示，离眼睛更近；键盘选中的提示位置不变。

## 1.4.2 — 2026-10-24

- 修复备用复制通道失败后，网页文字选区消失、无法继续扩选的问题。
- 修复拖选经过页面边缘，或焦点仍留在输入框时，正文偶尔不自动复制的问题。
- 日常选中复制操作和已有设置保持不变，所需权限不变。
- 修复重复打开表单时提示关联异常的问题。

## 1.4.1 — 2026-10-23

- 内部整理：设置读取与其它脚本用同一套实现，开关行为不变。

## 1.4.0 — 2026-10-23

- 菜单与面板标题跟其它脚本统一：从「选中复制设置」改叫「功能设置」。开关与复制行为不变。

## 1.3.1 — 2026-10-23

- 浏览器范围收窄：只支持 Windows 上的 Chrome / Edge。Mac 上的 Cmd+A 不再自动复制，其它复制方式不变。

## 1.3.0 — 2026-10-23

- 复制成功后，选区旁出现「已复制」小标签，约一秒后淡出；万一没写进剪贴板，会显示「复制失败」，不再无声失败。
- 新增脚本管理器菜单「选中复制设置」：可以关掉总开关、只关当前网站，也可以让输入框和富文本编辑器里选中时同样复制，或保留选中的首尾空白；改完立即生效。
- 安装或更新时会多看到“保存设置”和“脚本菜单”两项权限提示，脚本只在本机记录这些开关，不读取或上传网页内容。
- Mac 上 Cmd+A 全选后也会自动复制。
- 提示标签改贴在选区焦点上方；靠近页面顶部时自动翻到下一行，不再挡住刚选中的文字。
- 默认行为不变：拖动选中、双击、Shift 扩选、Ctrl+A 都会自动复制并去掉首尾空白；普通单击、输入框、富文本编辑器和程序化选区仍然不复制。
- 手机长按选中仍交给系统菜单处理，本次只保证电脑端。

## 1.2.0 — 2026-10-23

- 复制成功的小勾换成与其它脚本一致的样式，位置与出现时长不变。
- 剪贴板写入增加降级通道：脚本管理器不可用时改走浏览器剪贴板，再不行用隐藏输入框兜底。
- 行为不变：拖动选中、双击、Shift 扩选、Ctrl+A 都会自动复制并去掉首尾空白；普通单击、输入框与富文本编辑器里不复制。
- 页面里合成的鼠标 / 键盘事件仍然不触发复制；每个 frame 仍单独生效。

## 1.1.5 — 2026-10-23

- 补充作者主页、问题反馈链接与英文名称、英文简介；功能不变。
