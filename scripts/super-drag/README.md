# 拖拽打开

拖拽文本搜索，拖拽链接在新标签页打开，拖拽图片查看。

| 项目 | 值 |
| --- | --- |
| Greasy Fork | [580630](https://greasyfork.org/zh-CN/scripts/580630) |
| 当前版本 | 2.9.7（2026-10-26） |
| 迁移状态 | 已迁移：`src/` 模块，界面使用 `@ui` |
| 匹配站点 | `https://*/*`、`http://*/*`（`@noframes`，`document-end`） |
| 授予权限 | `GM_getValue`、`GM_setValue`、`GM_registerMenuCommand`、`GM_openInTab` |
| 设置键 | `settings`（旧键，未改名），单个对象 |

## 行为

| 操作 | 结果 |
| --- | --- |
| 选中文字后拖动 | 用当前搜索引擎搜索；拖动的文字本身是 http(s)/ftp 地址时默认直接打开，可在设置里改成「仍然搜索」。文字在 Shadow DOM 里也能识别 |
| 拖拽进行中 | 鼠标旁只显示系统的「复制」加号光标；脚本自己隐藏浏览器生成的低分辨率缩略图 |
| 按在选中的字符上拖动 | 即使压着链接或图片也按文字搜索；按在选区之外才按链接 / 图片处理 |
| 拖动链接 | 新标签页打开链接（默认后台，可改前台）；图片和搜索结果跟随同一设置 |
| 拖动图片 | 新标签页打开深色查看器；可改成直接打开原图；`blob:` / `data:` 图片始终直接打开原地址 |
| 拖动时按住 Shift | 这一次在前台打开 |
| 在设置里关掉某一类 | 这类拖拽交还网页原生行为，另外两类照常；页面上有选中文字时也不会改去搜索它 |
| 拖进输入框 / 富文本编辑框 | 不接管，交给页面原生插入 |
| 在设置面板里拖选文字 | 不接管：拖选说明文字只是普通选择，不会搜索或打开页面 |
| 按住 Ctrl / Cmd / Alt 拖动 | 不接管 |
| 页面自己的 `draggable` 元素 | 不接管；链接与图片本身除外（站点常显式标成可拖动），没有地址的链接 / 占位图片仍交还页面 |
| 按 Esc 取消拖拽 | 不打开页面，随后的点击也不受影响 |
| 网页取消拖拽，或从系统拖入文件 | 不沿用先前拖拽的链接 / 文字 / 图片；外来文件交给页面 |
| 拖拽后浏览器补发的点击 | 只有落在拖拽起点、且发生在 400ms 内的那一次被吞掉；点别处与更晚的点击都不受影响 |

## 结构

```text
src/
├─ main.ts                 # 入口：装监听、注册菜单、懒建面板
├─ settings.ts             # 设置 schema / 默认值 / 归一化 / 存储
├─ search.ts               # 引擎列表、拼搜索地址、自定义地址校验
├─ features/
│  ├─ dnd.ts               # 拖拽事件与状态机
│  ├─ drop-action.ts       # 纯判断：接管谁、打开什么、前台还是后台
│  ├─ hit-test.ts          # 命中链接 / 图片、页面拖拽归谁（穿透 Shadow DOM）
│  ├─ selection.ts         # 选区读取与命中（含 Shadow DOM 作用域选区）
│  ├─ editable.ts          # 输入框与可编辑区域判断
│  ├─ openers.ts           # 开标签页、图片查看器页面

└─ ui/settings-panel.ts    # @ui 面板组合
```

## 设置面板

入口是油猴菜单「功能设置」，没有悬浮按钮。第一次打开时才创建 UI 与面板，普通页面零 DOM。

面板固定在屏幕正中（440px 宽，内容多时内部滚动），分为：

- 拖拽类型：文字 / 链接 / 图片三个开关；
- 文字拖拽：搜索引擎、自定义搜索地址（含实时示例与校验）、网址文字直接打开或搜索；
- 链接与图片：新标签页打开方式、图片打开查看器或原图。

存储中自定义的搜索引擎 ID 即使与对象原型属性同名（如 `toString`），仍保留原 ID，并显示普通文字标签。

底部为恢复默认 / 取消 / 保存。原版的「使用方式」提示已并入面板顶部说明和各字段说明。

## 已知取舍

- 居中面板保持非模态：不加遮罩、不锁页面滚动，点面板外不关闭；关闭用 ×、Esc 或取消。
- 拖拽效果保持 `copy`（光标带加号）。脚本能控制的只有浏览器生成的拖拽缩略图：用已挂进文档、有布局的 16×16 透明 canvas 顶掉它；加号光标本身由浏览器与系统缩放绘制，脚本无法改动其清晰度。
- 设置表单不用 `createDialog`：它的按钮点击即关闭并返回结果，校验失败会变成「关掉再弹」。
- 自定义搜索地址选填；选了「自定义」但地址无效时保存会被拦下。
- 图片查看器仍是独立 blob 页面（深色居中），没有改成浏览器原生图片页。
- 查看器 blob 只靠 5 分钟定时回收；页面卸载时提前回收会让刚打开、还没加载完的查看页变成空白。
- 关掉某一类后，这类拖拽交还网页原生行为；文字拖拽被关掉时，按在选区里也不会转而打开下面的链接，按在链接 / 图片上时也不会转去搜索别处残留的选区。
