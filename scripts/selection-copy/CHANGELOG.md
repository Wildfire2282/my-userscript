# 变更记录

## 1.4.2 — 2026-10-24（待发布）

- 日常选中复制操作和已有设置保持不变，所需权限不变。
- 整理更新前的检查安排，让界面操作与设置变化得到更完整的检查；尚未完成发布前验证，未上线。

## 1.4.1 — 2026-10-23

- 内部整理：设置读取与其它脚本用同一套实现，开关行为不变。

## 1.4.0 — 2026-10-23

- 菜单与面板标题跟其它脚本统一：从「选中复制设置」改叫「功能设置」。开关与复制行为不变。

## 1.3.1 — 2026-10-23

- 浏览器范围收窄：只支持 Windows 上的 Chrome / Edge。Mac 上的 Cmd+A 不再自动复制，其它复制方式不变。

## 1.3.0 — 2026-10-23

- 复制成功后，选区旁出现「已复制」小标签，约一秒后淡出；万一没写进剪贴板，会显示「复制失败」，不再无声失败。
- 新增脚本管理器菜单「选中复制设置」：可以关掉总开关、只关当前网站，也可以让输入框和富文本编辑器里选中时同样复制，或保留选中的首尾空白；改完立即生效。
- 安装或更新时会多看到“保存设置”和“脚本菜单”两项权限提示，脚本只在本机记录这些开关，不读取或上传网页内容。
- Mac 上 Cmd+A 全选后也会自动复制。
- 提示标签改贴在选区焦点上方；靠近页面顶部时自动翻到下一行，不再挡住刚选中的文字。
- 默认行为不变：拖动选中、双击、Shift 扩选、Ctrl+A 都会自动复制并去掉首尾空白；普通单击、输入框、富文本编辑器和程序化选区仍然不复制。
- 手机长按选中仍交给系统菜单处理，本次只保证电脑端。

## 1.2.0 — 2026-10-23

- 复制成功的小勾换成与其它脚本一致的样式，位置与出现时长不变。
- 剪贴板写入增加降级通道：脚本管理器不可用时改走浏览器剪贴板，再不行用隐藏输入框兜底。
- 行为不变：拖动选中、双击、Shift 扩选、Ctrl+A 都会自动复制并去掉首尾空白；普通单击、输入框与富文本编辑器里不复制。
- 页面里合成的鼠标 / 键盘事件仍然不触发复制；每个 frame 仍单独生效。

## 1.1.5 — 2026-10-23

- 补充作者主页、问题反馈链接与英文名称、英文简介；功能不变。
