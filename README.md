# my-userscript

Wildfire2282 的用户脚本合集。装好之后，对应的网站会多出一些方便的小功能：一键复制、拖拽打开、批量抓链接之类。

四个脚本的界面已经统一：设置窗口、悬浮按钮和操作提示看起来像同一个产品的一部分。

> 这个仓库由 AI 助手维护。你不需要看懂代码，也不需要运行任何命令。

## 安装与更新

1. 浏览器里先装一个脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 点表格里的「点此安装」，浏览器会弹出安装页，确认即可。
3. 以后有更新时，管理器会自动检查；也可以在管理器里手动点「检查更新」。
4. 脚本更新会自动发布到 Greasy Fork，通常几分钟内就能在管理器里看到新版本。

## 想要新功能或改哪里

直接用中文说清楚想要的效果就行，不需要懂技术。例如：

- 「捕获链接的窗口太窄，帮我加宽一点」
- 「选中复制之后别再弹那个提示了」
- 「超级拖拽加一个用百度搜索的选项」

把这三件事说清楚最省事：**在哪个网站**、**现在是什么表现**、**你希望变成什么样**。

## 遇到问题
